# Minimal One-Screen Developer Portfolio

A minimalist, editorial one-screen developer portfolio for Soham Sangole, Software Engineer 1 at Bank of America. Built with Astro and Tailwind CSS.

---

## Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build
```bash
npm run preview
```
